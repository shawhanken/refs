**最后更新**: 2026-01-24
**版本**: 1.0

## 📋 概述

本文档旨在帮助开发者了解如何在 PVM 上编写高效、可靠的 Python 应用，包括支持的 Python 特性、限制、最佳实践和常见陷阱。

## ✅ 完全支持的 Python 特性

### 基本数据类型

**✅ 支持**：

```python
# 所有基本类型都完全支持
import rustpython_checkpoint as rpc

# 数字
integer = 42
floating = 3.14
complex_num = 1 + 2j

# 字符串
text = "Hello, PVM!"
multiline = """
    Multi-line
    string
"""

# 布尔值
flag = True

# None
value = None

# Checkpoint 可以保存所有这些类型
rpc.checkpoint("state.rpsnap")
```

### 容器类型

**✅ 支持**：

```python
# 列表
numbers = [1, 2, 3, 4, 5]
mixed = [1, "two", 3.0, None]
nested = [[1, 2], [3, 4], [5, 6]]

# 元组
coordinates = (10, 20)
immutable_data = (1, "two", 3.0)

# 字典
user = {"name": "Alice", "age": 30, "active": True}
nested_dict = {"level1": {"level2": {"value": 42}}}

# 集合
unique_numbers = {1, 2, 3, 4, 5}
frozen_set = frozenset([1, 2, 3])

# 所有容器类型都可以正确序列化
rpc.checkpoint("containers.rpsnap")
```

**注意事项**：
- 字典的 key 必须是可哈希的类型
- 集合的元素必须是可哈希的类型
- 嵌套容器的深度没有硬性限制，但建议保持合理

## ⚠️ 有限制或需要特别注意的特性

### 浮点数

**⚠️ 注意**：PVM 使用软件浮点库（SoftFloat）以确保确定性执行。

```python
# 浮点数运算支持，但结果可能与标准 Python 略有不同
result = 0.1 + 0.2  # 使用 SoftFloat
```

### 集合（Set）

**⚠️ 注意**：标准 `set` 在确定性执行中可能有问题，建议使用 `ordered_set`。

```python
# 标准 set（可能有问题）
my_set = {1, 2, 3}

# 推荐：使用 ordered_set（如果可用）
from ordered_set import OrderedSet
my_ordered_set = OrderedSet([1, 2, 3])
```

### 哈希

**⚠️ 注意**：哈希种子固定为 0（`PYTHONHASHSEED=0`），确保确定性。

```python
# 哈希结果是确定性的
hash_value = hash("test")  # 结果固定
```

## ❌ 不支持或禁止的特性

### 禁止的操作

以下操作在 PVM 中**禁止**或**不支持**：

1. **非确定性操作**
   - `time.time()` - 使用 `pvm_host.context().timestamp_ms` 替代
   - `random.random()` - 使用 `pvm_host.randomness()` 替代
   - `os.urandom()` - 禁止

2. **文件系统操作**
   - `open()` - 禁止
   - `os.path.*` - 禁止
   - 文件读写 - 禁止

3. **网络操作**
   - `socket.*` - 禁止
   - `urllib.*` - 禁止
   - HTTP 请求 - 使用 Runner 系统替代

4. **进程和线程**
   - `multiprocessing.*` - 禁止
   - `threading.*` - 禁止
   - `subprocess.*` - 禁止

5. **序列化**
   - `pickle` - 禁止（非确定性）
   - 使用 CBOR 替代

### 标准库限制

**白名单模块**（允许使用）：
- `math` - 数学函数（使用 SoftFloat）
- `json` - JSON 处理
- `collections` - 部分集合类型
- `itertools` - 迭代工具
- `functools` - 函数工具

**黑名单模块**（禁止使用）：
- `time` - 使用 Host API 替代
- `random` - 使用 Host API 替代
- `os` - 禁止
- `sys` - 部分功能受限
- `socket` - 禁止
- `pickle` - 禁止

## 📝 Checkpoint 使用规范

### 基本使用

```python
import rustpython_checkpoint as rpc

# 在函数内使用 checkpoint
def process_data(data):
    result = []
    for item in data:
        processed = process_item(item)
        result.append(processed)
        
        # 在循环中设置 checkpoint
        rpc.checkpoint("checkpoint.rpsnap")
    
    return result
```

### 最佳实践

1. **Checkpoint 位置**
   - ✅ 在循环迭代之间
   - ✅ 在函数调用之后
   - ✅ 在状态更新之后
   - ❌ 不要在异常处理块中间
   - ❌ 不要在 finally 块中

2. **Checkpoint 频率**
   - 不要过于频繁（影响性能）
   - 在关键状态变更点设置
   - 考虑恢复成本

3. **状态管理**
   - 确保所有需要恢复的变量都在作用域内
   - 避免使用全局可变状态
   - 使用显式的状态管理

## 🔧 常见错误和陷阱

### 错误 1：在嵌套函数中使用 checkpoint

```python
# ❌ 错误
def outer():
    def inner():
        rpc.checkpoint("checkpoint.rpsnap")  # 可能有问题
    inner()

# ✅ 正确
def outer():
    # 在顶层函数中使用
    rpc.checkpoint("checkpoint.rpsnap")
    def inner():
        # 不使用 checkpoint
        pass
    inner()
```

### 错误 2：使用非确定性模块

```python
# ❌ 错误
import time
import random

current_time = time.time()
random_value = random.random()

# ✅ 正确
import pvm_host

context = pvm_host.context()
current_time = context.timestamp_ms
random_bytes = pvm_host.randomness(b"my_domain")
```

### 错误 3：在循环中频繁 checkpoint

```python
# ❌ 错误（性能问题）
for i in range(1000):
    process(i)
    rpc.checkpoint("checkpoint.rpsnap")  # 太频繁

# ✅ 正确
for i in range(1000):
    process(i)
    if i % 100 == 0:  # 每 100 次 checkpoint 一次
        rpc.checkpoint("checkpoint.rpsnap")
```

## 📚 最佳实践

### 1. 状态管理

```python
# ✅ 推荐：使用显式状态管理
def handle_message(msg):
    state = pvm_host.get_state(b"my_state")
    if state is None:
        state = {}
    else:
        state = json.loads(state)
    
    # 更新状态
    state["counter"] = state.get("counter", 0) + 1
    
    # 保存状态
    pvm_host.set_state(b"my_state", json.dumps(state).encode())
    
    return b"ok"
```

### 2. 错误处理

```python
# ✅ 推荐：明确的错误处理
def process_data(data):
    try:
        result = complex_operation(data)
        return result
    except ValueError as e:
        # 记录错误但不中断执行
        pvm_host.emit_event("error", str(e).encode())
        return None
```

### 3. Gas 管理

```python
# ✅ 推荐：合理使用 Gas
def expensive_operation():
    # 预估操作成本
    estimated_gas = 10000
    
    # 检查剩余 Gas
    if pvm_host.gas_left() < estimated_gas:
        raise OutOfGasError()
    
    # 执行操作
    result = do_expensive_work()
    
    # 消耗 Gas
    pvm_host.charge_gas(estimated_gas)
    
    return result
```

### 4. 事件发射

```python
# ✅ 推荐：使用有意义的事件主题
def transfer(from_addr, to_addr, amount):
    # 执行转账
    do_transfer(from_addr, to_addr, amount)
    
    # 发射事件
    event_data = {
        "from": from_addr,
        "to": to_addr,
        "amount": amount
    }
    pvm_host.emit_event("transfer", json.dumps(event_data).encode())
```
