# DevEx & Cowchat — 产品设计与用户旅程对齐


## 两条入口，同一个后端

Cowboy 面向两类不同用户，但共享同一套底层能力（RPC API、Actor 部署管线、链上状态查询）：

```
                                                ┌──────────────────┐
  技术开发者 ──── DevEx CLI ──────────────────→   │                  │
                                                │  Cowboy Devnet   │
                                                │  (RPC / Chain /  │
  非技术用户 ── Cowchat ── LLM 翻译层 ────────→.   │   Actor Engine)  │
                              (自然语言→         └──────────────────┘
                               CLI命令/RPC调用)
```

两条路径的最终目标一致：**让用户在 Cowboy 上成功部署和运行 Actor。** 区别在于入口方式不同——技术用户直接使用 CLI 命令，非技术用户通过自然语言对话，由 LLM 翻译为等价的 CLI 命令和 RPC 调用。**本质上 Cowchat 是 CLI 的自然语言前端。**

---

## 用户旅程一：DevEx（技术开发者路径）

面向会写 Python 的开发者，通过 CLI 和 SDK 完成全流程。

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       DevEx 用户旅程地图                                      │
├─────────────┬──────────┬────────────┬──────────┬────────────┬───────────────┤
│ ① 安装      │ ② 设置   │ ③ 开发     │ ④ 部署   │ ⑤ 观察     │ ⑥ 迭代        │
│ (首次使用)   │          │            │          │            │               │
├─────────────┼──────────┼────────────┼──────────┼────────────┼──────────────┤
│ 用户通过     │ 创建或连接 │ 使用脚手架   │ 一行命令  │ 查看Actor   │ 根据观察结果   │
│ 一行命令     │ 钱包，     │ 初始化项目  │ 将Actor  │ 运行状态、   │ 修改代码，     │
│ 安装CLI     │ 并从水龙   │ ，在模板基   │ 部署到    │ 交易执行    │ 重新部署，     │
│ 工具        │ 头领取     │ 础上编写    │ Devnet   │ 结果和      │ 再次观察，     │
│             │ 测试代币  │ 自己的Actor │          │ 日志        │ 循环迭代       │
├─────────────┼──────────┼────────────┼──────────┼────────────┼──────────────┤
│ cowboy      │ cowboy   │ cowboy     │ cowboy   │ cowboy     │ 复用③④⑤     │
│ CLI         │ wallet   │ init       │ actor    │ actor logs │ 的工具        │
│ 安装器       │ create/  │ + SDK      │ deploy   │ + 状态      │ 循环操作      │
│             │ connect  │ + 文档      │          │ 查询       │              │
│             │ + faucet │            │          │            │              │
└─────────────┴──────────┴────────────┴──────────┴────────────┴──────────────┘
```

**核心体验**：开发者从安装到看到自己的 Actor 在链上运行，应该尽可能快速和顺畅。每一步都有明确的命令和即时反馈。

## 用户旅程二：Cowchat（非技术用户路径）

面向不会写代码的用户，通过自然语言对话完成与 DevEx 相同的工作流程。Cowchat 背后接入 LLM，将用户的自然语言指令翻译为与 DevEx 路径完全相同的 CLI 命令和 RPC 调用。**步骤本质上相同——只是交互方式不同。**

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                       Cowchat 用户旅程地图                                        │
├──────────┬────────────┬────────────┬────────────┬────────────┬──────────────────┤
│ ① 进入   │ ② 入驻     │ ③ 描述     │ ④ 确认     │ ⑤ 监控     │ ⑥ 调整           │
│          │ (首次       │            │  并部署     │            │                  │
│          │  使用)      │            │            │            │                  │
├──────────┼────────────┼────────────┼────────────┼────────────┼──────────────────┤
│ 用户打开  │ 获得可用     │ 用自然语言  │ Cowchat    │ 用户在聊天   │ 用户通过对话       │
│ Cowchat  │ 账户（含     │ 描述想要   │ 展示生成的   │ 中问：      │ 告诉Cowchat       │
│ 网页，    │ 钱包和      │ 创建的      │ Actor方案  │ "我的Actor  │ "调整一下策略"，    │
│ 进入     │ 测试代币）    │ Actor：   │ 供用户审阅   │ 跑得怎样？"  │ 系统自动修改       │
│ 聊天界面  │ （钱包管理   │ "帮我做个   │ ，确认或    │ Cowchat     │ 并重新部署。      │
│          │ 方案待定）.  │ 交易机器人" │ 修改，      │ 在聊天中回   │ 全程在同一个       │
│          │            │            │ 然后部署    │ 复状态摘要   │ 对话中完成        │
├──────────┼────────────┼────────────┼────────────┼────────────┼──────────────────┤
│ Cowchat  │ 钱包创建/   │ 对话式      │ 方案预览    │ 对话式       │ 对话式调整         │
│ 网页     │ 连接        │ 意图输入    │ 并在聊天内   │ 状态查询     │                  │
│          │ + 领取代币  │            │ 确认部署    │ 与回复       │                  │
│          │ (机制待定)  │            │            │            │                  │
├──────────┼────────────┼────────────┼────────────┼────────────┼──────────────────┤
│          │ LLM 将入驻  │ LLM 理解   │ LLM 生成    │ LLM 将     │ LLM 将"调整"       │
│ 无需LLM  │ 请求翻译为   │ 用户意图    │ Actor代码   │ "我的Actor  │ 翻译为代码修改     │
│          │ wallet命令 │ 并拆解为     │ 并转换为    │ 跑得怎样？"  │ + cowboy actor   │
│          │ + faucet   │ 结构化需求   │ cowboy     │ 翻译为RPC   │ deploy 部署命令   │
│          │            │            │ actor      │ 查询命令    │                  │
│          │            │            │ deploy命令  │            │                  │
└──────────┴────────────┴────────────┴────────────┴────────────┴──────────────────┘
```

**核心体验**：打开 Cowchat 并完成入驻后，整个旅程都在对话中完成。**用户无需离开对话界面。**
