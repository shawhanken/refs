## Key Findings Summary

### 🔴 Critical Deviations (Block Whitepaper Compatibility)
1. **Cryptographic scheme**: secp256k1 (ECDSA) vs Ed25519 — foundational; breaks Ethereum interoperability
2. **Address format**: 20-byte vs 32-byte ed25519 PublicKey — invalidates all address-related specifications
3. **Transaction structure**: missing `chain_id`/`to`/`value`/`tip_per_cycle`/`tip_per_cell`/`access_list` — 6 required fields absent
4. **Transaction encoding**: canonical CBOR vs custom binary — wire-level incompatibility
5. **Signing hash function**: keccak256 vs SHA256 — signature verification incompatibility
6. **Basefee adjustment**: EIP-1559 dual-channel mechanism entirely unimplemented — core fee model missing

### 🟠 Important Deviations (Impact Security / Determinism)
1. **Randomness**: threshold-BLS VRF vs SHA256(block_hash) — exploitable by proposer
2. **PVM determinism whitelist**: includes `weakref`/`_thread` — non-deterministic modules
3. **GasCosts parameters**: multiple costs off by 10× or more (transfer 10K vs 21K, storage_read 50 vs 500, send_message 10K vs 1K)
4. **Block lacks VRF**: on-chain randomness verification impossible
5. **No fanout/reentrancy limits**: missing 1,024 message cap and 32-depth recursion limit
6. **No memory/tmp limits**: missing 10 MiB heap and 256 KiB scratch space caps

### 🟡 Missing Features (Prioritized)
1. **Entitlements permission system** (§15)
2. **Ethereum interoperability** (§16): Bridge, EventListener, EIP-712
3. **Dedicated Lanes** (§17.9): 4 execution lanes
4. **PVM Host API gaps**: `get_balance`/`transfer`/`read_mailbox`/`verify_signature`/`hash`/`log` (note: `self_address` and `get_block_info` are available via `context()`)
5. **Timer full suite**: tiered queue, GBA bidding, progressive deposit, surcharge, 256 cap
6. **CIP-20 Platform Token operations**
7. **State Rent**: rent, eviction, grace period
8. **Inflation / Block Rewards**
9. **Slashing / Governance**

13. **`set_interval` recurring timer**
