04

为什么 token 陡增,份数却没涨?

是「每份审计变深(轮数翻 2–4 倍)」,不是「审得更多」,也不是「上下文变胖」。 三个实测指标一对比就清楚:

时期基线静态上下文轮/会话token/份
07-20 分水岭前17K202.7M
07-24 分水岭前40K172.1M
07-27 分水岭后18K789.5M
07-30 分水岭后29K5712.6M

三条证据链:

① 不是上下文膨胀。 基线静态上下文(系统提示+CLAUDE.md+记忆+工具)全程稳定 17–41K,没涨,07-27 反而更低。

② 不是份数增长。 份数只翻倍,token/份却翻 3–4 倍。

③ 真因 = 每份轮数 15–20 → 45–78。 轮数一多,每轮重读整段累积会话,cache-read/轮 也从 74K 涨到 149K(第 60 轮要重读前 59 轮)。

超线性:轮数 ~2.5× × 每轮上下文 ~2× ≈ 每份 token ~4–6×

为什么轮数陡增 —— 队列的 PR 性质变了。 7 月中下旬前多是浅 PR(docs/examples 清理),几轮审完;07-26/27 起被深共识面 PR 填满,每个都要大量 scout / prove / 跨仓 grep / 变异推理 / 多视角对抗验证:

  • CBQS #290(前后 24 轮 escalate)、计价单位族 cp#67/68 · cowboy#294/295
  • PVM lockdown 系列(#1227/1228/1235/1237/1224/1232,读 pvm 源码 + 跨仓确认)
  • tx-contract slice(#1244/1245/1246/1249,overlay + golden 差分)
  • eth-LC bridge #1200(r5→r8,2500 行 diff + BLS/gindex 归因)· runner 盲签栈(#200–205 多轮)
可操作结论: 深审/多轮 PR 单份成本超线性——每多一轮都按 cache-read 价重读整段会话。控成本的杠杆在「缩短单份会话轮数」(更早分诊、限无谓 scout),而非「少审几个 PR」。

06

常见困惑

Q为什么报告 $5.1k,/usage 却小得多?

计费模式不同。你是订阅(固定月费),per-token 没扣;本报告是「折合 API 单价」的假想值。/usage 是真实口径,它小是对的。

Q为什么审计份数(345)比巡检轮数(442)少?

很多轮队列为空(没 PR / 都已在当前 head 审过)。空轮仍跑 find_targets + 小结,有小额成本但 0 份。

Q「每份 $14.9」和明细里 9.5M/份对不上?

$14.9 是全期平均,掩盖巨大方差:早期浅 PR ~$5,深审高峰 ~$25–30。看单日更准(见 03、04)。

Qcache-read 占 97% token 却只 60% 成本,矛盾?

不矛盾。cache-read 单价最低($1.5/M),output 贵 50×($75/M)。token 量和花的钱是两个维度(见 02)。

Q一个 PR 审好几轮,成本算重了吗?

没算重也没漏。每轮在不同 head,各是独立审计(各烧 token),已分别计入 345。多轮 PR 总成本 = 轮数累加。

Q「每份成本」是纯一个 PR 的开销吗?

不是。一轮审 2–3 个 PR 共享 find_targets/小结,「每份」= 整轮 ÷ 份数,已摊入共享开销(见 01)。

07

口径说明 · API 等值 ≠ 实际支出

关键这是订阅计费,不按 token 扣费

本机为 OAuth 订阅登录(Claude Max),非 API key 按量计费(配置无 apiKeyHelper,存在 ~/.claude/.credentials.json)。

报告中所有金额是「假如走 API 单价会折合多少」的参考等值,不是真实账单。订阅为每月固定费,per-token 从未被扣。因此 /usage 显示的成本远小于本报告 —— 那是订阅额度内的真实口径,是对的;本报告用于评估这套自动化「相当于多少 API 价值 / ROI」。

标准档 · 主口径(≤200K 上下文)
$5,142 / 月
in $15 · out $75 · 1h-write $30 · read $1.5 (每 M)
1M 溢价档 · 上限(>200K 约 2×)
≈ $10,300 / 月
深审多在 200K 边界附近 · 每份 ≈ $29.8 · 乘数有不确定性
「1M 溢价档上限」是什么意思? 本机是 Opus 百万 token 长上下文版(claude-opus-4-8[1m])。对单次请求上下文 >200K 的部分,Anthropic 按约 2×溢价计费。于是同一批用量有两个折算价:$5,142 = 假设全部按标准价(下限);$10,300 = 假设每次都落进溢价档(上限,几乎不可能全中)。真实值在两者之间、更靠近 $5.1k —— 只有累积到 >200K 的深度多轮会话才走溢价。即:这是个区间 $5.1k~$10.3k,「上限」是天花板,不是另一个真实数字。

一句话 —— 一份 PR 深审 ≈ 610 万 token / API 等值 $15(cache-read 占 6 成成本);近一月 442 轮、345 份,API 等值 ≈ $5.1k。单份成本随审查深度(轮数)超线性上升,7 月底转深共识 PR 后每份翻 4–6 倍。订阅下均非真金白银支出,/usage 才是实际口径。
